“销销”数字人直播带货桌面端 ​

将 AI 数字人、商品内容管理与直播开播流程整合到一款桌面应用中，让商家能够更高效地准备直播内容，并通过数字人完成商品讲解与互动。

产品概览 ​

“销销”是一款面向电商场景的跨平台数字人直播桌面软件，基于 Electron 构建，支持 Windows 与 macOS。产品围绕直播准备、内容编排、数字人生成和开播管理形成工作流，结合语音合成（TTS）、语音识别（ASR）、虚拟形象驱动及实时渲染等能力，提供可配置、可交互的虚拟主播解决方案。

多语言支持，面向国内外用户

直播内容列表集中展示直播状态、渲染进度、版本类型和内容模式，便于管理多场直播任务。

核心产品能力 ​

AI 主播与数字人内容 ​

用户可选择或创建主播形象，配置主播表现要求，并组织主播素材与内容。系统将数字人形象、语音和讲解内容结合，用于生成商品介绍或直播内容，降低重复录制与内容准备成本。

AI 主播工作区支持形象、主播表现和历史创作内容管理。

商品讲解与直播脚本 ​

围绕商品组织直播内容，支持商品列表、商品讲解脚本、视频片段和活动信息等素材的配置。主播可按商品准备讲解内容，并通过预览和编辑流程检查画面与脚本效果。

时间轴编排与素材处理 ​

通过时间轴组织视频、语音和商品讲解等内容，支持对素材进行排列、预览与调整。时间轴式编辑将原本分散的素材配置转化为可视化流程，帮助用户更直观地把握直播内容的顺序与节奏。

知识库问答与直播互动 ​

系统可配置 FAQ、商品信息、课程内容等知识库，在直播互动中提供精准问答、商品推荐及活动介绍。结合意图识别与情感分析，让回复更贴合用户问题和对话语境，提升互动的相关性与自然度。

多种开播方式 ​

根据直播间和设备环境，可选择不同的开播链路：

  • RTMP 推流：将应用生成的直播画面与音频推送至直播平台。
  • OBS 虚拟摄像头：将数字人画面作为摄像头源，接入 OBS 或其他直播软件。
  • 窗口捕获：配合直播伴侣捕获应用窗口，适配平台客户端的开播流程。

技术方案 ​

模块技术与职责
桌面端与界面Electron 提供跨平台桌面运行环境；Vue 3、TypeScript 构建交互界面与业务模块
进程通信Electron 主进程负责桌面能力与生命周期管理，渲染进程承载界面，通过 IPC 传递受控的业务指令与状态
AI 能力服务Python 服务（Flask / FastAPI）承载 TTS、ASR、LLM 等模型能力，通过 HTTP 或 WebSocket 与桌面端协作
音视频与内容负责数字人画面、视频素材、语音内容及直播脚本的组织、预览和输出
构建与更新使用 electron-builder 构建 Windows / macOS 安装包，并支持应用自动更新

整体链路可概括为：桌面界面组织直播任务，Electron 主进程协调本地桌面能力，AI 服务处理模型请求，最终将生成内容交给预览、渲染和直播输出流程。

工作亮点 ​

1. 面向真实直播工作流设计复杂界面 ​

这类产品并非单一表单或展示页，而是涵盖直播管理、主播形象、商品讲解、视频片段、脚本和时间轴等多个环节。工作重点是把复杂配置拆解为清晰、可理解的操作步骤，让用户能够从素材准备逐步进入预览和开播。

2. 关注桌面端的状态协同与操作反馈 ​

桌面应用涉及渲染进程、主进程和外部 AI 服务之间的协作。界面需要清楚呈现任务状态、处理进度和异常反馈，并处理异步请求、重复操作和窗口生命周期等情况，避免用户在生成或渲染期间失去操作上下文。

3. 将 AI 能力包装成可用的业务功能 ​

TTS、ASR、LLM 等模型能力只有融入实际场景才能形成完整体验。围绕商品知识库、直播脚本、主播形象及互动问答组织操作入口，使用户能以业务概念使用 AI，而不必理解模型调用细节。

4. 兼顾多系统交付与直播环境适配 ​

基于 Electron 面向 Windows 和 macOS 交付，需要考虑安装包构建、应用更新、不同系统下的窗口行为与资源访问；同时提供 RTMP、OBS 虚拟摄像头和窗口捕获等开播选择，适配多种直播环境。

5. 提升内容编排的可视化与可控性 ​

通过视频片段、商品关联和时间轴等可视化编辑方式，让内容结构和播放顺序更直观。用户可以先预览、再调整、最后开播，降低内容配置错误带来的返工。

项目价值 ​

“销销”把数字人生成、商品内容准备、直播脚本编排、智能互动和开播能力串联为一套桌面工作流。项目的挑战不仅是实现 AI 功能，更在于将多进程桌面架构、异步模型服务与直播业务界面整合成稳定、易理解的产品体验。

相关技术栈： Vue 3、TypeScript、Electron、Python、Flask / FastAPI、TTS、ASR、LLM、WebSocket / HTTP、electron-builder。
