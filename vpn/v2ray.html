TIP

V2Ray / Xray 是常见的代理网络内核，x-ui 是一个基于 Xray Core 的 Web 管理面板，可以用图形界面创建节点、管理用户、设置流量和过期时间。本文面向新手，目标是搭建一个个人学习和合法访问用途的自建节点。

请根据所在地法律法规合规使用相关技术，不要用于违法用途，也不要把面板账号、节点链接或订阅链接公开分享。

搭建完成后，你会得到一个 x-ui 管理面板，并可以在里面创建 VLESS、VMess、Trojan、Shadowsocks 等不同类型的入站配置。新手建议先用面板默认支持的稳定方案，跑通之后再调整更复杂的传输和 TLS 设置。

Disclaimer: This project is only for personal learning and communication, please do not use it for illegal purposes, please do not use it in a production environment

前提条件 ​

  • 一台可通过 SSH 登录的海外 VPS 服务器；
  • 一个域名，可选。如果你只是先测试，可以暂时使用服务器 IP；
  • 一台用于连接的客户端设备，比如 Windows、macOS、Android 或 iPhone；
  • 能复制并执行简单 Linux 命令。

购买国外的服务器 ​

自建节点的前提是先有一台可以访问海外网络的 VPS。常见选择有 Vultr、Nube VPS 等。

没有服务器的朋友可以先注册账号并购买最低配置的虚拟主机。个人学习用途通常 1CPU、512MB 内存就可以起步，后续如果连接人数或流量增加，再升级配置。

详细的注册和部署实例教程可以参考另一篇文章 《优质的 VPS 搭建代理推荐》。等你可以使用 SSH 远程登录到服务器，就可以继续往下操作。

TIP

系统建议选择 Debian 12 或 Ubuntu LTS。服务器刚开通后，先确认能用 ssh root@服务器IP 登录。

安装 x-ui 面板 ​

登录到你的服务器，执行:

bash
bash <(curl -Ls https://x-ui.alireza0.dev/install.sh)

这个脚本会安装 x-ui 面板和 Xray Core，并启动一个 Web 服务。安装完成后，终端通常会输出面板访问地址、端口、用户名和密码，请把这些信息保存好。

如果脚本询问是否继续安装、是否设置端口、是否配置用户名密码，新手可以先按提示操作。遇到不确定的选项，优先使用脚本推荐值，安装完成后再进入面板修改。

安装后也可以在服务器执行下面的命令查看菜单：

bash
x-ui

常用操作包括查看面板信息、重启面板、更新 x-ui、修改面板端口和重置账号密码。

首次登录后的安全设置 ​

浏览器打开脚本输出的面板地址，例如：

txt
http://服务器IP:面板端口/

第一次登录后建议立刻完成这些设置：

  • 修改默认用户名和密码；
  • 修改默认面板端口，避免继续使用容易被扫描的端口；
  • 如果服务器提供商有防火墙规则，只开放 SSH 端口、面板端口和节点端口；
  • 节点链接、二维码、订阅链接只给自己使用，不要发到公开页面；
  • 后续定期执行 x-ui 菜单里的更新操作。

WARNING

如果浏览器打不开面板，先检查 VPS 控制台的防火墙、安全组是否放行了面板端口，再检查服务器系统防火墙是否允许该端口访问。

创建一个节点 ​

进入 x-ui 面板后，通常按下面的顺序操作：

  1. 打开「入站列表」或「Inbounds」；
  2. 点击「添加入站」；
  3. 协议选择 VLESS 或 VMess，新手优先选择面板里默认提示最完整的方案；
  4. 端口填写一个没有被占用的端口，例如 443、8443 或其他自定义端口；
  5. 添加一个客户端，设置好备注、过期时间和流量限制；
  6. 保存配置，然后确认入站状态是启用。

如果你有自己的域名，可以把域名解析到 VPS IP，再在面板里配置 TLS、证书或 Reality 等高级选项。没有域名时，先用 IP 跑通基本连接也可以。

导出客户端配置 ​

节点创建完成后，在入站列表里找到对应的客户端，复制分享链接、订阅链接，或者打开二维码。常见格式大概是：

txt
vless://...
vmess://...
trojan://...

客户端导入时不要手动改动这些链接，先直接导入并测试连接。确认能正常访问后，再回来优化协议、端口、流量和过期时间。

客户端下载 ​

不同系统使用的客户端不一样：

系统常见选择配置方式
Windowsv2rayN导入分享链接或订阅链接
Androidv2rayNG扫描二维码或导入链接
macOSV2RayU、NekoRay、Clash Verge 等导入链接或订阅
iPhone / iPadShadowrocket、Stash 等扫描二维码或导入订阅

新手不要直接下载 v2ray-core 或 Xray-core 当客户端使用。它们更偏向核心程序，图形客户端会帮你处理配置文件、订阅更新和连接切换。

常见问题 ​

面板打不开 ​

优先检查三件事：

  • 面板端口是否写对；
  • VPS 后台安全组是否放行面板端口；
  • 服务器防火墙是否拦截了端口。

客户端导入后连不上 ​

先确认节点端口已经放行，然后检查客户端里的地址、端口、协议、UUID、传输方式是否和 x-ui 面板一致。只要有一个字段不一致，就可能连接失败。

能连上但速度慢 ​

自建节点速度主要受 VPS 线路、服务器地区、本地网络和晚高峰拥堵影响。可以优先换服务器地区，其次再考虑升级配置或更换服务商。

要不要开多人共用 ​

不建议新手把自建节点当成多人服务。多人共用会带来流量、账号管理、安全和合规风险。个人学习用途，给每台设备单独建客户端会更清晰。
