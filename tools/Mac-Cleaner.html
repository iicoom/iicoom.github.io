Mac 的磁盘空间经常不是被某一个大文件占满，而是慢慢堆积在应用缓存、浏览器缓存、日志、临时文件和已经卸载的软件残留中。macOS 自带的「储存空间」可以查看大致分类，却很难继续定位和清理体积庞大的「系统数据」。

这篇文章介绍一套免费开源的解决方案：使用 Mole 负责扫描和清理，再通过 MoleUI 提供图形界面。实测清理前后，系统已用空间从 469.52 GB 降到 430.56 GB，释放了约 38.96 GB。

清理前请先确认

系统清理会删除缓存、日志和临时文件。重要数据应提前备份，开始清理前关闭正在运行的应用，并逐项检查扫描结果。无法确认用途的目录，不要勾选。

为什么需要第三方清理工具 ​

常见的 Mac 清理软件通常采用订阅制，免费版本只能扫描，真正执行清理时仍然需要付费。以 CleanMyMac 为例，其清理、应用卸载和性能维护等功能被划分到不同的付费方案中。

付费软件的优势通常是界面成熟、操作简单，但如果需求只是查看磁盘占用、清理缓存和卸载残留，开源工具已经可以覆盖大部分场景。

免费方案：Mole 与 MoleUI ​

Mole 是一款运行在终端中的开源 macOS 系统维护工具，能够完成深度清理、应用卸载、磁盘分析、系统优化和状态监控。它使用 GPL-3.0 协议开源，清理过程在本机执行。

MoleUI 是 Mole 的第三方图形界面，将扫描结果按类别、大小和勾选状态展示出来，更适合不熟悉命令行的用户。MoleUI 已内置 Mole，不需要提前安装命令行版本，并提供适用于 Intel 和 Apple Silicon 的通用安装包。

注意项目之间的区别

  • tw93/Mole：免费开源的官方命令行工具；
  • Zhili1004/MoleUI：免费开源的独立社区图形界面，底层调用 Mole；
  • Mole for Mac：Mole 作者提供的商业图形应用，不是本文使用的 MoleUI。

MoleUI 目前包含以下主要功能：

功能用途
Clean扫描系统缓存、应用缓存、日志、临时文件和废纸篓
Uninstall卸载应用并查找关联的配置与残留文件
Optimize刷新缓存与部分系统服务
Analyze分析磁盘目录和大文件占用
Status查看 CPU、内存、磁盘和网络状态
Touch ID为需要管理员权限的操作提供系统授权

下载与安装 ​

本文使用的是 MoleUI 图形版，安装过程如下：

  1. 打开 MoleUI Releases；
  2. 下载名称中包含 universal.dmg 的安装包；
  3. 打开 DMG，将 MoleUI 拖入「应用程序」目录；
  4. 启动 MoleUI，等待首次扫描完成。

项目说明中标注的最低系统版本为 macOS 11，并且安装包已签名和公证。为避免下载到被修改的副本，建议只从 GitHub 项目的 Releases 页面获取安装包。

如果更习惯终端，也可以直接安装 Mole：

bash
brew install mole

安装后先通过 --dry-run 预览将要清理的内容，再决定是否执行：

bash
mo clean --dry-run
mo clean

通过 Homebrew 安装时，项目当前建议使用 macOS 14 或更高版本；较旧系统可以参考 Mole 仓库中的脚本安装方式。

使用 MoleUI 清理空间 ​

1. 扫描可清理内容 ​

打开左侧的 Clean，MoleUI 会扫描缓存、日志、临时文件等内容，并在每个类别右侧显示预计可释放的空间。

本次扫描中，占用最大的项目是 System Caches，约为 34.69 GB；浏览器缓存约为 1.76 GB。两项已经占到本次可清理空间的绝大部分。

2. 检查清理项目 ​

不要看到较大的数字就直接全部清理，建议特别检查以下内容：

  • 浏览器缓存：清理后网页资源需要重新下载，首次打开网站可能变慢；
  • 应用缓存：部分应用下次启动时会重新生成索引或缓存；
  • 开发工具缓存：Xcode、Node.js、npm、pnpm、Gradle 等缓存可能很大，但重新构建时需要再次下载；
  • 废纸篓：清空后无法通过废纸篓恢复文件；
  • 邮件缓存：可能触发邮件内容或附件重新同步。

确认后再点击 Start Cleanup。涉及系统目录时，macOS 会弹出系统授权窗口；只应在确认操作来自 MoleUI 时授权。

3. 清理后重新检查 ​

清理完成后，回到「系统设置 → 通用 → 储存空间」查看结果。macOS 会在后台重新统计各类空间，因此分类数字可能需要等待一段时间才会稳定。

测试效果 ​

清理前，磁盘共 494.38 GB，已使用 469.52 GB，其中「系统数据」占用 163.38 GB。

清理后，已使用空间下降到 430.56 GB，「系统数据」下降到 124.07 GB。

对比项清理前清理后变化
已使用空间469.52 GB430.56 GB减少 38.96 GB
系统数据163.38 GB124.07 GB减少 39.31 GB

这次清理释放了约 39 GB 空间，结果与 MoleUI 扫描出的缓存体积基本一致。需要注意，macOS 会动态调整「系统数据」「macOS」和「应用程序」的归类，分类差值不一定等于实际释放空间；判断效果时，应优先比较磁盘的总已用空间。

安全使用建议 ​

Mole 和 MoleUI 的源码公开并不代表每一项都适合无条件删除。清理工具的风险来自删除行为本身，建议遵循下面几条原则：

  1. 第一次使用时只清理明确可重建的缓存和日志，不处理不认识的目录；
  2. 清理前退出浏览器、开发工具和其他正在写入数据的应用；
  3. 重要项目、照片和文档应有独立备份，清理工具不能替代备份；
  4. 使用命令行版时，先运行 mo clean --dry-run，再用 mo history 查看历史操作；
  5. 如果空间主要被照片、视频、虚拟机或项目依赖占用，应先使用 Analyze 定位，而不是反复清理系统缓存。

总结 ​

如果希望免费清理 Mac，又不想直接操作终端，MoleUI 是一个容易上手的选择；如果更看重更新速度、可审查的命令和精细控制，则可以直接使用 Mole 命令行版。

这类工具最适合处理长期积累的缓存、日志和卸载残留，不适合把所有扫描结果都当作“垃圾”。先预览、再筛选、最后清理，通常比追求一次释放最多空间更稳妥。
